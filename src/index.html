// About me

Turning messy data into things that work

I'm a graduate student at UIUC finishing an MS in Computer Science alongside a BS in Computer Engineering. Most of my work sits where machine learning meets real-world data that refuses to cooperate.

That's meant estimating corn yield from satellite imagery at Phillips 66, building hotspot analysis pipelines for tumor research at NCSA, and classifying academic disciplines from scraped Wikipedia articles with the Mathematical Language Processing Group. Lately I've been shipping InSevak, an offline-first insurance wallet built on React Native and Postgres.

I'm looking for roles where I can keep working on hard problems close to the data.

Projects

    RISC-V Out-of-Order Processor

    An out-of-order RISC-V core built on explicit register renaming with M-extension support. Pairs a tournament branch predictor — 2-level and g-share combined with a return address stack — against a parametrized set-associative cache with next-line prefetching and a post-commit store buffer.

    • SystemVerilog
    • RISC-V
    • Verdi
    • Design Vision

    86% branch prediction accuracy on standard benchmarks

  • Oct 2024

    4-Way Set Associative Pipelined Cache

    A 2-stage pipelined cache with 16 sets, 4 ways, and 32-byte cachelines, handling both hits and misses. Uses a pseudo-LRU replacement policy with a write-back, write-allocate strategy to cut miss penalties.

    • SystemVerilog
    • RISC-V
    • Verdi

    16 sets × 4 ways fully parametrized design

  • Nov 2023

    Linux Kernel from Scratch

    A ground-up operating system with multi-level paging, a flat-structured file system, and an interrupt descriptor table handling exceptions, system calls, and interrupts. Includes drivers for keyboard, RTC, and the Intel 8259 PIC.

    • C
    • x86
    • Linux

    10 system calls plus multi-terminal round-robin scheduling

    Pocket Tanks on FPGA

    A turn-based multiplayer game rebuilt on an Intel MAX10 FPGA, driven by a finite state machine bridging C and SystemVerilog. Keyboard interrupts run through the embedded NIOS II CPU, with VGA output and frame buffering for display.
